# Definition Of Done

Status: repo audit 2026-07-11.

For product/code work:

- Existing implementation audited first.
- No duplicate route/flow added unless documented.
- Correct service boundary used.
- API response compatibility reviewed.
- Database migration is additive, indexed, and service-owned.
- Search/index impact reviewed.
- Analytics/event impact reviewed.
- Security/privacy impact reviewed.
- Mobile and desktop UI checked.
- Loading/empty/error states handled.
- Tests run or test gap documented.
- Docs updated when product meaning changes.

For documentation-only work:

- Claims cite source files/commands.
- Unknowns are labeled as unknown.
- No secrets are copied.
- No production code, schema, dependency, or UI is changed.
